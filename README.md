# Ephemeral Gamerz

A game review site where users can track games they've played and share their reviews and opinions with others.

## MVP Features

### User Accounts
- Sign up / log in / log out
- Basic user profile (username, avatar, bio)

### Game Playlist
- Add a game to a personal playlist by entering game details (title, platform, genre, release year, cover image)
- Edit or remove games from the playlist
- View playlist as a personal library of games played/owned

### Reviews & Opinions
- Write a review/opinion for a game in the playlist
- Rate a game (e.g. 1-5 stars or 1-10 score)
- Edit or delete your own reviews
- View all reviews for a given game

### Game Discovery
- Browse/search games that have reviews
- View a game's page showing its details, average rating, and all user reviews

### Core Site Pages
- Home page (recent/popular reviews)
- Game detail page
- User profile page (their playlist + their reviews)

## Possible Future Features (Post-MVP)
- Likes/comments on reviews
- Follow other users
- Tags/filters for genres and platforms
- Integration with an external game database API for auto-filled game details
